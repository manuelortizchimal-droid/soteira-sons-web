Privacidad y condiciones de las experiencias

Última actualización: octubre de 2026.

Estado del sitio: el formulario de contacto aún no está conectado a un sistema de recepción. No se envían ni almacenan solicitudes a través de ese formulario. Antes de habilitarlo, se publicarán los datos completos del responsable del tratamiento y un medio efectivo para ejercer derechos de privacidad.

1. Responsable y contacto

Marca comercial: Soteira & Sons. La identidad legal, domicilio de contacto y correo de privacidad del responsable están pendientes de incorporación. Este documento es provisional y no debe utilizarse como aviso definitivo para captar datos personales.

2. Datos y finalidades previstas

Una vez habilitado el formulario, se prevé solicitar nombre, correo, teléfono opcional, servicio de interés y mensaje opcional, para responder solicitudes, informar sobre disponibilidad y coordinar una experiencia. No se usarán estos datos para publicidad ni listas de difusión sin consentimiento separado cuando corresponda. Evita compartir información sensible, datos de terceros o información médica.

3. Conservación, proveedores y derechos

Antes de activar la captación se definirán plazos de conservación, medidas de seguridad, encargados y transferencias aplicables. Se habilitará un canal para solicitar acceso, rectificación, cancelación u oposición y, cuando proceda, revocar el consentimiento conforme a la legislación mexicana.

4. Alojamiento y datos técnicos

Este sitio utiliza GitHub Pages. El proveedor puede procesar registros técnicos, como direcciones IP y datos de acceso, conforme a sus políticas. Las imágenes externas pueden generar solicitudes a proveedores de contenido.

5. Naturaleza de los servicios

Tarot y canalizaciones se ofrecen como experiencias espirituales, culturales y de interpretación simbólica. Las narrativas, imágenes y mensajes del oráculo no constituyen hechos verificados, predicciones garantizadas ni prueba de comunicación con personas fallecidas. Ninguna experiencia garantiza resultados específicos.

6. Límites y decisiones personales

El contenido no sustituye atención médica, psicológica, jurídica o financiera. Las decisiones personales corresponden a cada visitante. No se recomienda utilizar estas experiencias como único fundamento de decisiones importantes. No se realizarán afirmaciones de diagnóstico, curación ni contacto sobrenatural comprobado.

7. Contratación y reclamaciones

Antes de contratar se deberán comunicar precio total, alcance, duración, modalidad, políticas de cancelación, reembolso y un canal de atención de reclamaciones. Ninguna disposición de este documento limita derechos irrenunciables de las personas consumidoras ni excluye responsabilidades que la ley no permita excluir.

8. Cambios

Los cambios relevantes se reflejarán en esta página con fecha de actualización. El uso del sitio no equivale por sí solo al consentimiento para tratar datos personales.
